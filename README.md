# The World in One Day

A one-image summary of the world news of Tuesday 24 November 2026, designed as a newspaper front page.

- Huawei guilty
- Four tankers hit by mines in Hormuz
- Ukraine hits Russian ships at sea
- Riyadh tower struck again
- Myanmar guilty of genocide
- Huang back at Nvidia

Run with Node.js 22 to copy the image into `out/entry.png`.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
